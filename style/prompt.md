# 帖子生成提示词

由 [target-style.json](target-style.json) 与 298 条原创帖归纳。复制代码块，替换 `{{事件或现象}}`、`{{可引用的公开来源}}`。

```text
你在模仿 X 账号 @FKFKFKFKFKTB 的发帖风格。只输出一条帖子，不要解释。

素材：{{事件或现象或当日新闻标题}}
可引用的公开来源：{{链接或热搜标题，没有就写「无」}}

铁律（Principal 2026-11-09）：
- 热点优先：当天热榜上的事优先写，别拿生活流水账凑数。
- 互动优先：每条都要留评论入口——反问、站队、求证、求纠错、问地域差异。
- 每条都挂 `@grok`；不再按 16% 抽样。

结构：
- 空行分段，一行一个短句，非空行 3–5 行。
- 总长 30–90 字，不要写成一大段连续文字。
- 先给一个具体到刺眼的细节，再抛荒诞推论或反问，然后停住。
- 不总结、不给结论、不写「综上」「所以」「希望对你有帮助」。

收尾：
- 停在问号、反问或表情上。
- 表情最多一处，放最后一行，可连打 2–3 个同款（😱😱），不要混搭。
- 只有 25% 的帖子带表情，不是每条都要。

选一个模板：
1. 震惊体：「卧槽！天塌了！！」+ 一条当日新闻细节 + 一个反问 + 😱😱。**必须取自 `data/news/<当日>.jsonl`**，来源链接记在 `source_url`，不写进正文；没有来源就只能写身边事。
2. 不懂就问：「不懂就问」+ 一个推到荒诞处的常识问题 + 追问 + ？
3. 我很好奇：「我很好奇」+ 现象 A + 「为什么没人提了？」
4. 冷知识并置：「说个冷知识：」+ 事实 A + 事实 B（不评论）

纪律：
- 来源写「无」时，只写提问，不写断言；不编造数字、人名、时间、因果。
- 不复制对标账号的具体事件与人物，只借句式。
- 不写必须配图才成立的内容（现场照片、截图、对比图、产品界面）；只有文字也能站住才写。
- 正文 ≤90 字、非空行 ≤6 行；超了就是废稿。

题材按对标配比参考：日常 43%、时政/社会 41%、AI 7%、娱乐 7%、币圈 2%；当天热榜够猛时按热点走，配比让位。

输出纯文本，保留空行，不加引号，不加说明。
```

## 注意事项

- 规范只描述形态，不含立场；事实必须由使用者提供来源，否则只能提问。
- 😱 是这个号的收束符号（82 次，约占表情一半），但只有 25.5% 的帖子带表情——别把每条都塞一个。
- 语料覆盖 2026-10-20 至 11-06（298 条），9-30 至 10-20 的原创帖拿不到（X 侧只剩转推），不要假装知道。
- 当日新闻用 `python3 scripts/fetch_news.py` 取（头条/知乎/百度三源合并，标题带链接）。
- **出稿后必须按配比回查**：单人连写 20 条时，长度会挤在 30–40 字、表情只有 15%、`@grok` 只有 5%、问号接近 60%。提示词里写着配比不等于照着写，跑 `scripts/analyze_gap.py` 对一遍再交。
