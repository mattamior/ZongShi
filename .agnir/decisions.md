# Decisions

- **批量去重口径（2026-11-09，Principal 否决按主题去重）**：只按正文去重——归一化空白后完全相同，或 difflib 相似度 ≥0.92，视为重复；保留「选定 > 备选 > 池」中优先级最高的一条，其余预置「重复」并默认隐藏。同主题换角度的帖子是不同写法，不删。本次 404 条中命中 19 条。
- **单条配图覆盖（2026-11-09）**：按来源匹配的图不对时，在 `data/drafts/image_overrides.json` 给该条指定关键词或图片 URL，优先级高于来源图。T1/BLG 三条（b019/b020/b115）已指定 Faker 夺冠照。
- **审稿页（2026-11-09）**：`site/build_site.py` 把当天稿池渲染成静态页 `site/index.html`（数据内嵌、无外部依赖）。「复制=合格并标记已用、重复=与已发内容撞车、废弃=不合格、编辑=优化」；配图用新闻原图（原文 og:image 优先、图片搜索兜底、没有就不显示，不做上传），右侧显示并标注来源，图片复制与文字复制分开；状态存浏览器 localStorage，导出 JSON。因为剪贴板 API 需要安全上下文，必须用 http 打开，`file://` 下复制不可用。
- **产能与红线口径（2026-11-09，Principal）**：每号每小时 4 条——两号合计 8 条/小时、192 条/天，每 15 分钟一个位；每天产出 384 条候选（每个位 2 选 1）。「不要怕红线」指允许更冲的措辞、讽刺与站队，但仍不编造事实、不点名指控私人、不放外链。
- **选稿口味（2026-11-09）**：Principal 从 24 条试稿中只留 5 条。留下的都是「具体主体 + 可被争论或拆穿的矛盾点」（官方动作反差、奇闻追一个具体数字、政策利益反差、行为站队）；纯感慨、科普式提问、生活流水账被弃。第二轮又否掉 t04/t05/t08/t09/t10/t11（说「很没意思」），并亲手把 t07 改成「是谁tm排板的」——要骂到具体的人或动作，允许粗口；只做中性反问会被判没意思。第三轮又否掉 u08/u09/u10——「公告发了吗」「谁负责浇」「输了算谁的」这类事务性追问同样被判没意思：要有对手（谁在骗、谁在贪、谁在装）、要有荒诞落差，或者能直接站队；问流程、问手续的都算废稿。
- **稿件排版（2026-11-09，Principal 指定）**：`data/drafts/*.md` 用「`### <id> <时段>·<模板>·<字数>字` + 代码块」逐条排列，不加汇总大表、不在每条之间插来源行；来源统一放文末「## 来源」。代码块便于整条复制发布。
- **Principal 铁律（2026-11-09）**：热点优先、互动优先；每条帖都必须挂 `@grok`。模板不限条数——此前 `style/prompt.md` 里「同一模板一天内不要用超过两次」是推导约束、不是 Principal 要求，已移除。
- **文档不写机器路径（2026-11-09）**：同一仓库在多台机器上克隆编辑，`.agnir/` 与交接文档不记录机器专属绝对路径或本机登录状态；需要位置时写“运行时传入的仓库根”。`.agnir/evidence/` 下的历史证据保留当时路径，不改写。
- **当前状态优先（2026-11-07）**：研究 P0–P2 已完成；11-06 已形成真实账号 `lapplax / @MattDjj` 的运营交接记录，目标为 mt.ai 接管、增长优先，内容方向为时政 / 日常评论。**Principal 11-07 确认交接未完成，周一（11-09）继续**。此前“仅研究”与原人设为历史阶段安排；本次文档同步不启动账号动作。
- **后续规则（2026-11-06，见 P2 evidence 与 HANDOVER.md）**：原创上限 60→90 字，非空行 ≤6 行；不写依赖配图的内容；正文不放来源链接，来源存元数据；批量出稿做分布自检，废弃 KS；回关策略废弃，勿用 `follow_back.py`。
- **历史缺口（2026-11-06）**：Principal 核对最早可见原创为 10-20 后决定不再追补更早历史；缺口保留为覆盖限制，不再阻塞后续工作。

- **早期研究阶段（2026-11-05，已由后续交接记录更新）**：当时只做采集、分析、规范、自评，不接账号、不发布。发送能力（`send.py` / `record_sent.py` / `metrics.py`）不在研究范围内，启用需单独授权并重新评估平台风险。
- **项目骨架（2026-11-05）**：接入 Agnir，Core `1.0` / profile `repository-filesystem/1.0` / 分发 `v1.0.2`（revision `b5626394ec40a5cb7a28c01892acde07cc0adc8e`），与参考项目 `mt.ai` 同版。
- **争议内容（2026-11-05）**：按对标账号 `@FKFKFKFKFKTB` 的处理手法复刻——提问包装、反差并置、骂公敌、热搜跟评；配比按实测（18 条原创里涉时政 8 条、荤与擦边 3 条）。**不复刻它的具体断言**：每条争议帖必须能指到公开报道、热搜或原帖，指不到就只写提问。禁止无来源断言、攻击普通用户/挂人/人肉、涉未成年、民族与地域仇恨、性向攻击、投资建议、医疗建议、冒充身份。
- **长文体裁（2026-11-05）**："14 天上岸"类复盘长文整类延后，本号成功前不写；当前原创只保留短钩子（≤90 字、≤6 行；原 60 字上限已于 11-06 更新）。解禁门槛另行设定（建议：单周 50 万展示或达成上岸），届时语料取本号 `sent.jsonl`。
- **人设（2026-11-05）**：只做接口层——昵称后缀「（互～）」+ 一句话简介；不做身份层（学历、执业、机构、考试分数、收益数字、真实姓名）。被追问经历时降级为「不是专业的，随口一说」，不编细节。
- **原接口人设方案（2026-11-05，11-06 已作废）**：昵称 `ZongShi（互～）`，简介 `AI 弄潮儿`，**不做固定自称**——核验 186 条回复，自我称谓仅 4 条且非自称、第一人称「我」9 条（4.8%），对标号没有可识别标签；此前引用的「互浇侠」属 `@mattamior`，属误套。落盘于 `style/new-account.json`。现有账号资料以 `HANDOVER.md` 的 11-06 快照为准，未在本次在线核验。
- **简介不约束选题（2026-11-05，Principal 纠正）**：简介只是主页标签，内容一律对标原号。原号简介写「临床/AI/USMLE/币圈」，原创却有 39% 时政、28% 八卦——简介与选题本就无关。选题配比由 P1 从全量语料实测得出，不由简介推导。
- **采集口径（按实现区分）**：`collect_target.py` 走公开 FxTwitter 镜像，不发送 X cookie、token 或 API key；后续 `collect_user_timeline.py` 在用户指定的已登录 Chrome 标签页内调用只读 `UserTweets`，使用该会话认证。不得把后者描述为无登录采集；不将凭据写入文档或数据。原始页与加工结果保留，结论可离线复算。
- **完整性标准**："全量"需要游标真正耗尽或权威导出佐证。空页仍带 continuation cursor 时视为未耗尽，标注 `api_cursor_exhausted=false`；第三方快照永远不写成"账号全部历史"。
- **数据完整性**：保留帖子 ID、时间戳、规范 URL、原始正文、回复目标与被回复帖 ID；不转述、不补造字段。跨快照同一 ID 正文变化需单独记录，作者计数变化不算正文变更。
- **风格分析**：结论只基于已采集语料；区分稳定模式与试探性观察，例句必须带 ID；样本不完整或时间集中时下调置信度，不外推到账号全部历史。
