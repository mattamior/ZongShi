- **争议内容（2026-11-05）**：按对标账号 `@FKFKFKFKFKTB` 的处理手法复刻——提问包装、反差并置、骂公敌、热搜跟评；配比按实测（18 条原创里涉时政 8 条、荤与擦边 3 条）。**不复刻它的具体断言**：每条争议帖必须能指到公开报道、热搜或原帖，指不到就只写提问。禁止无来源断言、攻击普通用户/挂人/人肉、涉未成年、民族与地域仇恨、性向攻击、投资建议、医疗建议、冒充身份。
- **长文体裁（2026-11-05）**："14 天上岸"类复盘长文整类延后，本号成功前不写；当前原创只保留短钩子（≤60 字、≤6 行）。解禁门槛另行设定（建议：单周 50 万展示或达成上岸），届时语料取本号 `sent.jsonl`。
- **人设（2026-11-05）**：只做接口层——昵称后缀「（互～）」+ 一句话简介；不做身份层（学历、执业、机构、考试分数、收益数字、真实姓名）。被追问经历时降级为「不是专业的，随口一说」，不编细节。
- **接口人设定稿（2026-11-05）**：昵称 `ZongShi（互～）`，简介 `AI 弄潮儿`，**不做固定自称**——核验 186 条回复，自我称谓仅 4 条且非自称、第一人称「我」9 条（4.8%），对标号没有可识别标签；此前引用的「互浇侠」属 `@mattamior`，属误套。落盘于 `style/new-account.json`。handle 与头像由 Principal 开号时手动决定。
- **简介不约束选题（2026-11-05，Principal 纠正）**：简介只是主页标签，内容一律对标原号。原号简介写「临床/AI/USMLE/币圈」，原创却有 39% 时政、28% 八卦——简介与选题本就无关。选题配比由 P1 从全量语料实测得出，不由简介推导。
- **采集口径**：只走公开接口（FxTwitter / FxEmbed 时间线端点），不发送 X cookie、账号 token 或 API key；原始响应逐页落盘，加工结果必须可离线复算。
- **完整性标准**："全量"需要游标真正耗尽或权威导出佐证。空页仍带 continuation cursor 时视为未耗尽，标注 `api_cursor_exhausted=false`；第三方快照永远不写成"账号全部历史"。
- **数据完整性**：保留帖子 ID、时间戳、规范 URL、原始正文、回复目标与被回复帖 ID；不转述、不补造字段。跨快照同一 ID 正文变化需单独记录，作者计数变化不算正文变更。
- **风格分析**：结论只基于已采集语料；区分稳定模式与试探性观察，例句必须带 ID；样本不完整或时间集中时下调置信度，不外推到账号全部历史。
