# 红线清单

`check_text.py` 按本文件的分节执行硬拦截。改这里之前先改判断，别只加关键词。

## 1. 一句都不许写

- **没来源的断言**：具体数字、伤亡、金额、判决、任免、死亡、被捕、病情，只要不是用户给的公开来源，一律不写。写成提问。
- **点名指控**：真实姓名 + 违法行为／丑闻／私生活。可以写现象，不写“某某干了什么”。
- **医疗与投资建议**：剂量、疗程、买什么、什么时候买、必涨必跌。
- **冒充与伪造**：假装官方通报、假装当事人、伪造截图描述、编造亲历（“我在现场”）。
- **联系方式与链接**：手机号、微信号、二维码、外链（来源锚点除外，且必须由用户提供）。

## 2. 高风险词（命中即拦）

断言口吻与谣言标记：

```
据传 据悉 内部消息 知情人 实锤 独家爆料 已证实 百分百 100% 必然 肯定会
```

绝对化与煽动：

```
所有人都 没有一个 彻底完蛋 亡国 灭族 血洗 清算
```

## 3. 形态硬规则

- 原创正文 **≤90 字**、非空行 **≤6 行**（PLAN §5；对标 95% 的帖子在 90 字以内）。
- 表情 **最多一种**，同款连打 **最多 3 个**，且只放在最后一行。
- `@` 只允许 `@grok`。
- 不写“综上”“所以”“希望对你有帮助”“以上”这类收尾。

## 4. 交付前必做

- 每条争议内容标来源锚点；没有来源就改成提问。
- `check_text.py` 必须零拦截才能进候选池，拦截记录留在 `data/eval/<ts>/guard.log`。
